# Spotkick

Interactive eSports web application built for peer-to-peer (P2P) penalty duels, featuring real-time matchmaking, multiplayer mechanics, and custom animations.
🚀 **Live Production Demo:** [Click here to launch Spotkick](https://spotkick.esoamerica4742.workers.dev)w


## Tech Stack

- Next.js / TypeScript
- Tailwind CSS
- Cloudflare Workers (Edge infrastructure)

## Core Features

- Real-time peer-to-peer match logic for head-to-head penalty duels.
- Custom game animations including shrinking ring mechanics and dynamic UI states.
- Low-latency backend handling powered by Cloudflare Workers.
